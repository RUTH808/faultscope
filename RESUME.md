# FaultScope | Industrial Fault Classification

Python, scikit-learn, Random Forests, Probability Calibration

- Built a 7-class classifier on 1,941 steel-fault records, achieving 0.781 macro-F1 on 389 held-out samples after validation-based model selection.
- Implemented calibrated confidence-based review, reaching 89.36% accepted-case accuracy at 60.41% coverage; published per-class metrics and a local inference API.

Measured offline benchmark results, not production business impact. Review README and reproduce the experiment before presenting the work in an interview.
